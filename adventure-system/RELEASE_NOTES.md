# QR City Quest Stage 12 RC1

**Adventures** opens the catalog and shows the current game. The original
QR City Quest remains built in. Installing a replacement warns before
discarding unfinished progress, and switching back starts a fresh original
playthrough.

Linear adventures follow locked scenarios and ordered checkpoints. Circular
adventures follow authored clues and visits. Both can use installed maps.
Non-linear adventures retain the Objectives navigation. Installed packages
keep their authored language when the app interface language changes.

Victory is saved before the completion screen appears. Confirmed replay starts
a fresh save for the installed adventure. Existing legacy progress migrates to
the new save format, with the original storage entry retained for recovery.
Existing base-game mods and preferences stay installed.

After successful app-shell installation, supported browsers can reopen local
adventures offline. Manual QR entry remains available when camera scanning
cannot start. The optional camera decoder is cached on a controlled online
load when the CDN responds. Browser storage can be cleared or evicted.

This is a review candidate. The production catalog in the repository is empty.
Physical device and hosting release gates remain open. The Spanish preview is a
test fixture with English fallback and remains an incomplete translation.
